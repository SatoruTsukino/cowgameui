# Agent Rules

## Planning & Approval Required
- **Do not build, edit, or execute code without a plan in place and explicit user review.**
- Workflow for any code implementation or modification:
  1. **Plan First**: Formulate a clear, structured plan outlining the proposed changes, architectural decisions, affected files, and verification/testing strategy.
  2. **User Review**: Present the plan to the user for review.
  3. **Approval**: Wait for explicit user review and approval before writing, modifying, or building code.
